# RC Slab Plugin — Handoff 2026-05-14

## 1. Project context

Plugin AutoCAD (nie BricsCAD) automatyzujący zbrojenie żelbetowych płyt fundamentowych (piled-raft slab) zgodnie ze standardem BS 8666. Plugin działa jako .NET DLL ładowana do AutoCAD 2015 i steruje programem ASD (AutoCAD Structural Detailing) wysyłając komendy tekstowe. Stack: C# .NET 4.8, AutoCAD 2015 API (`acmgd.dll`, `acdbmgd.dll`, `accoremgd.dll`), WPF (dialogi), EPPlus 4.5.3.3 (Excel), Newtonsoft.Json 13. Projekt powstał jako alternatywa/uzupełnienie pracy ręcznej w ASD dla firmy Speedeck Foundations Ltd.

## 8. Setup / build

### Wymagania
- AutoCAD 2015 zainstalowany w `C:\Program Files\Autodesk\AutoCAD 2015\` (ścieżki hardcoded w .csproj)
- .NET 4.8 SDK
- ASD (AutoCAD Structural Detailing) działający razem z AutoCAD

### Build

```
cd C:\Users\Dell\Desktop\ClaudeCode\AsdRcSlab
dotnet build AsdRcSlab.csproj
```

Output: `bin\Publish\AsdRcSlab.dll`

Alternatywnie: `build.bat` (zawartość do sprawdzenia).

### Wczytanie do AutoCAD

1. Otwórz AutoCAD
2. Przed buildem: `NETUNLOAD AsdRcSlab` (jeśli DLL już załadowana)
3. Zbuduj projekt
4. W AutoCAD: `NETLOAD` → wskaż `bin\Publish\AsdRcSlab.dll`
5. Ribbon "ASD RC Slab" pojawi się automatycznie

### Przepływ pracy

1. **ASD-PROJ** — utwórz/wczytaj projekt (`project.json`)
2. **ASD-GSETUP** — zaznacz pręty szablonowe H10 (B1/B2) i H12 (T1/T2)
3. **ASD-GBOT** — wskaż obrys płyty (warstwa `SD-PILED-RAFT`) → generuje pręty dolne
4. **ASD-GTOP** — wskaż obrys → generuje pręty górne
5. **ASD-PXIE** — wczytaj dane pali z Excel (arkusz PLOT.xlsx)
6. **ASD-PAA** — Assign PH + annotacja rysunku
7. **ASD-BMM** — sprawdź BBS (walidacja Excel)

### Dane testowe
- Punching data: plik Excel z arkuszem zawierającym kolumny: Pile ID, Util%, PunchingAction, LocationType
- Rysunki ASD: muszą mieć tytuł zawierający "REINFORCEMENT DETAILS OF SPEEDECK"
- Pręty szablonowe: entity ASD `rbcr_def_bar_bv` na warstwie `AutoCAD_Structural_Detailing_Bar distribution`
